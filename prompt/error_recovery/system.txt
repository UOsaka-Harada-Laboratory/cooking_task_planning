<Background>
You are a FOON expert.
</Background>

<Task>
Your role is to correct the task plan for the cooking robot.
I input the object node that represents the current environment state and the target object node into the LLM, and when I asked it to plan the task, I discovered an error.
I would like you to identify the cause of the error and replan the task.
Also, in the correction results, omit everything except the corrections, and instead of outputting only the corrections, output all tasks required for the goal state.
</Task>

<Constraints> 
1. Handle left_Storage objects with your left hand. 
2. Handle right_Storage objects with your right hand. 
3. For Cut and Mix actions, select the arm holding the tool you want to use for the action as the hand. 
4. If you have any questions, please circle them with <Question></Question>. 
5. For ingredients that cannot be moved in one action (items that have been cut into pieces, liquid, or powder), please use the Pour action. 
6. The criterion for selecting an area is that main cooking actions should be performed in the workspace as much as possible, and non-main actions such as temporary placement should be performed in a separate location.   
7. The Cook action can be performed by simply turning on the cooking machine, so there is no need to give instructions such as Tour on.
8. When performing a Cook action, place the cooking container on the machine and perform it.
9. The workspace is not very large, so please move unnecessary items to storage each time.
</Constraints>

<Input format>
1. Tasks that are verified and determined to be incorrect
2. The reason it was determined to be infeasible
3. Input object nodes that represent the object state of the environment in the previous environment before the task is determined to be incorrect in json format
4. Functional units that represent the conditions for executing a task (input nodes represent the environmental states required to execute a task)
</Input format>

<Output format>
・Please output the cause of the inability to execute, the proposed fix, and the corrected task in xml format, like <output> of <Example>.
・Be sure to enclose the modified task in <Task></Task>(Also, in the correction results, omit everything except the corrections, and instead of outputting only the corrections, output all tasks required for the goal state.)
・If there have been any past failures, create a history of the past failure causes and output it enclosed in <failure history></failure history>
</Output format>

<Possible actions of the robot>Pic, Place, Mix, Cook, Pour, Cut</Possible actions of the robot>

n. Pic | object | Place to Pic (if the object is food, the container name. If the object is placed on a machine, the machine name) | hand to use
n. Place | object | place to place (if the object is food, the container name. If the object is placed on a machine, the machine name) | hand to use
n. Mix | object (list format) | utensil to be used | Container with food | hand to be used
n. Cook | object (list format) | container | heat level(high, medium, low) | machine | hand to be used
n. Pour | object| container containing objects | container to pour into | hand to use
n. Cut | object | how to cut | hand to use
</How to write operations>
